**Phantom Findings: An Empirical Measurement of Code Grounding and Structural Hallucinations in Open-Source Vulnerability Reports**  
*Invarcore Research Contribution Candidate C3 (USENIX SAIS 2027 / OpenSSF WG #178)*

---

## 1. Problem Formulation

Open-source maintainers face an unprecedented surge of inbound automated vulnerability reports generated by AI tools, semi-autonomous pentesting bots, and bug-bounty submitters. OpenSSF WG Vulnerability Disclosures (Issues #178, #181, #182) and maintainers across high-profile projects (curl, Node.js, GNOME, Screenly) report that an overwhelming proportion of rejected reports cite **phantom file paths, fabricated symbols, out-of-bounds line numbers, or already-patched upstream code**.

While previous academic studies evaluated general text-classifier detectors or LLM reasoning benchmarks (e.g., Ding et al., SiMLA 2026), **no empirical study has measured the structural code-grounding rate of inbound vulnerability reports directly against target repository ASTs and git commit graphs**.

`c3-claim-checker` provides a deterministic, zero-LLM claim-checking harness that audits vulnerability report claims against target repository trees at the claimed Git version tag and upstream `HEAD`.

## 2. Six-Class Failure Taxonomy (F0–F5)

| Failure Class | Designation | Definition |
|:---|:---|:---|
| **F0** | `F0_VALID_ANCHOR` | Cited file path, function/symbol, and line range exist at claimed ref and remain unpatched upstream at report date. |
| **F1** | `F1_PHANTOM_PATH` | Cited file path does not exist in repository tree at claimed ref or upstream HEAD. |
| **F2** | `F2_PHANTOM_SYMBOL` | File exists at claimed ref, but cited function, method, or struct identifier does not exist in AST/symbol table. |
| **F3** | `F3_LINE_DRIFT_OR_OOB` | Cited line number exceeds file length at ref or points outside cited symbol boundaries. |
| **F4** | `F4_UPSTREAM_ALREADY_FIXED` | Cited code existed in an older release but was already modified/patched on `HEAD` prior to report submission. |
| **F5** | `F5_UNANCHORED_PROSE` | Report contains zero checkable file, line, or symbol anchors (speculative prose). |

---

## 3. Dataset Sampling Architecture

- **Stratum A (Negative Controls / Invalid Claims)**: Publicly closed invalid/spam/not-a-bug security issues (e.g., curl's public `vuln:NONE` issue disclosures under the Oct 26, 2026 policy, Screenly, Node.js).
- **Stratum B (Positive Controls / Ground Truth)**: Published Open Source Vulnerabilities (OSV) and confirmed GitHub Security Advisories (GHSAs) for the identical repositories and timeframes.
